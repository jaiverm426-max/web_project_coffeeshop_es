Triple Expresso

Descripción del proyecto

Triple Espresso es una página web para una cafetería y zona de estudio. El sitio permite a los usuarios conocer información sobre la cafetería, consultar sus horarios y dirección, reservar una mesa mediante un formulario y acceder a sus redes sociales.

El proyecto fue desarrollado utilizando:

HTML5 para crear la estructura semántica de la página.
CSS3 para los estilos, distribución, tamaños, colores y diseño visual.
Flexbox para organizar y alinear los diferentes elementos de la página.
Posicionamiento absoluto para algunos elementos decorativos, como el círculo del pie de página.
Google Fonts para utilizar las tipografías Inter y Noto Serif.
Estados :hover para añadir interactividad a los enlaces de navegación, el botón de reserva y los enlaces de redes sociales.
Formularios HTML con diferentes tipos de entrada, validación mediante atributos required y una casilla de aceptación de términos.

Planes de mejora

En el futuro me gustaría continuar mejorando el proyecto agregando funcionalidades que permitan ofrecer una experiencia más completa al usuario.

Una de las mejoras que me gustaría implementar es hacer que el formulario de reserva sea completamente funcional, de manera que las reservas puedan enviarse y almacenarse en un sistema. También me gustaría agregar una confirmación visual después de realizar una reserva.

Además, me gustaría seguir mejorando la adaptación de la página a diferentes tamaños de pantalla y aprender a incorporar JavaScript para agregar mayor interactividad y funcionalidades dinámicas al sitio.
